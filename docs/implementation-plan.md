# GitNest 实施计划

依据：[产品与技术设计](design.md)第 10 节。开始日期：2026-11-13。

## 执行方式

- 按阶段推进；每批围绕一个可验证的结果提交到本地 Git。
- 每批提交前完成对应验证，在 [实施记录](implementation-log.md) 中记录变更、命令、结果和后续事项。
- 上游源码单独导入，保留许可证和固定版本信息；产品改造在后续提交进行。
- 产品功能以真实 Git 仓库验证引用、索引和文件内容；界面变更另做桌面检查。

## 记录约定

每批记录包含日期、对应阶段、变更结果、验证命令与实际结果、关键决策及接续点。提交哈希在后续记录中引用，避免在提交内预填自己的哈希。安装包与构建日志存于忽略的 `artifacts/`，文档保留可复现命令和结果摘要。
