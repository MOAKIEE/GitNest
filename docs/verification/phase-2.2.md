## 刷新与显示规则

- 状态摘要读取完整未提交文件数，包含未跟踪文件，与修改页的列表过滤选项分别处理。
- 主工作树也进入原工作树区域，每项显示别名、分支、手动完成状态、路径、分类数量、同步状态及刷新时间；完整路径、HEAD、锁定及本地获取时间可展开查看。
- 普通工作目录事件只更新当前目录状态；首次发现工作树时读取其状态。其他目录保留原刷新时间，工具栏刷新按钮、右键刷新及 F5 主动刷新全部工作树。
- 每个仓库页面最多并行读取两个工作树，旧代次及已关闭页面的结果不覆盖新状态。恢复焦点时刷新当前目录和注册列表。
- 监听补充关联工作树的 index、FETCH_HEAD 及配置变化，保持现有去抖刷新方式。
- 同步数量标注为本地引用缓存；FETCH_HEAD 时间是本地记录时间。无上游、上游缓存缺失、没有获取记录及目录不可读均独立表述。
- 别名和手动完成标记写入 GitNest 配置目录中的 `worktree-tasks.json`。比较目标的存储字段已准备，选择和累计差异界面接续批次 2.3。
